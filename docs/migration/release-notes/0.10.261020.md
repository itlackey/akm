# akm v0.10.261020 migration notes

This beta fixes Claude plugin health reporting, adds coordinated channel
switching, and reduces repeated fenced identifiers in search content.

The next index pass refreshes existing content projections and changed embedding
inputs automatically. No manual database or configuration migration is required
when upgrading from 0.10.261019.

After installing this beta, `akm upgrade --channel next` switches the CLI and
installed Claude, Codex and OpenCode plugins together. The existing `--next`
flag keeps its prior behavior. To return to stable, use
`akm upgrade --channel latest`; if the target version is older, add
`--allow-downgrade`. Changed settings receive backups, and the command reports
any harness that could not finish switching. Restart the harness after updates.

Claude health now uses native installation metadata. It reports conflicting or
incomplete installation selections as unknown instead of choosing a cached
version. This can change a previous warning without changing the installation.

If upgrading from 0.9, first follow the
[0.9 to 0.10 migration guide](../v0.9-to-v0.10.md).
