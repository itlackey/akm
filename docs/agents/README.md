# Agents

Documentation for wiring AI agents into akm.

`akm help agents` prints the short guide for agents, and `akm help agents
--full` the complete one. `akm hints` prints the complete guide, and `akm hints
--detail brief` the short one. All four print the guide embedded in the CLI
(`src/assets/hints/cli-hints-full.md` and `cli-hints-short.md`), so you can also
read those files directly.

- [Agent Install Guide](agent-install.md) -- Short redirect covering the install shape (binary, `akm setup --yes`, a source, an index, `akm help agents`); for the exact no-prompts command sequence, see the [headless install recipe](../guides/recipes/headless-install.md)
