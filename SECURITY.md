# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.9.x | Yes |
| Older | No |

## Reporting a vulnerability

Report security issues privately through GitHub Security Advisories:
<https://github.com/itlackey/akm/security/advisories/new>

If that is unavailable, email `itlackey@gmail.com` with `SECURITY` in the
subject. Include reproduction steps, the akm version, and your operating
environment.
