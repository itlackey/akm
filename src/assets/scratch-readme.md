# Bundle scratch space

Use this directory for temporary drafts, investigation notes,
experiments, generated artifacts, and intermediate outputs.
AKM does not index its contents.

Clean up after yourself:
- Remove your temporary files when the work is finished.
- Move or incorporate reusable findings into indexed bundle content.
- Leave this README and other people's active work intact.

AKM does not clean this directory automatically. Do not keep the
only copy of important information here.
